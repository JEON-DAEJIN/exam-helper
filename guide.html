📚 시험공부 도우미 — 설치와 사용법

아빠가 만든 시험 대비 도구야. 수업 PDF를 ChatGPT에 넣으면 플래시카드와 시험문제를 만들어 주고, 이 앱에서 외우고 풀고 오답노트까지 할 수 있어. 설치 프로그램도, 추가 요금도 없어.

1. 아이패드에서 쓰기 (추천)

  1. 아이패드 Safari로 이 주소를 열어:
    https://jeon-daejin.github.io/exam-helper/
  2. 위쪽 공유 버튼(□↑) → 홈 화면에 추가 → 추가
  3. 이제 홈 화면의 시험공부 아이콘을 누르면 앱처럼 열려. 기록이 사라지지 않게 꼭 이 아이콘으로 열어 줘.
  4. 공부할 때는 화면 나누기로 왼쪽에 ChatGPT 앱, 오른쪽에 시험공부를 띄우면 복사·붙여넣기가 편해. (화면 위 가운데 ··· 누르기 → 화면 나누기)

PC에서도 같은 주소로 열 수 있어. 단, PC와 아이패드의 기록은 따로 저장돼. 옮기고 싶으면 한쪽에서 '백업 파일 저장' → AirDrop·카톡·iCloud로 파일 넘기기 → 다른 쪽에서 '백업 불러오기'.

1-2. PC에서 파일로 쓰기 (인터넷 없이)

  1. 메일에 첨부된 시험공부도우미.html 파일을 내려받아.
  2. 잘 지워지지 않는 곳으로 옮겨 둬. 예: 문서 폴더 안에 시험공부 폴더를 만들어서 넣기
  3. 파일을 더블클릭하면 크롬이나 엣지에서 열려. 그게 끝!
  4. 편하게 쓰려면 파일을 마우스 오른쪽 버튼으로 끌어서 바탕화면에 바로 가기 만들기를 하거나, 열린 화면을 브라우저 즐겨찾기(Ctrl+D)에 추가해 둬.

💡 처음 열면 "예시 자료로 먼저 구경하기"를 눌러 봐. 플래시카드·문제풀기가 어떻게 되는지 바로 볼 수 있어. 다 봤으면 예시 자료는 '관리 → 자료 삭제'로 지우면 돼.

2. 수업 PDF로 문제 만들기

  1. 앱에서 ＋ 새 자료 만들기 → 과목, 자료 이름(예: 3단원), 카드·문제 수를 고르고 부탁 글 만들기
  2. 부탁 글 복사 → ChatGPT 열기 → 입력창 왼쪽 ＋로 수업 PDF 첨부 → Ctrl+V 붙여넣고 보내기
  3. ChatGPT 답에 나온 코드 상자 오른쪽 위 복사 버튼 → 앱 3단계 칸에 붙여넣기 → 불러오기 → 저장하고 공부 시작

더 많이 만들고 싶으면 그 자료의 관리 → ＋ ChatGPT로 더 만들기. 같은 ChatGPT 대화창이면 PDF를 다시 안 올려도 돼.

3. 공부하는 법 추천

  • 매일: 홈의 오늘 복습 시작만 눌러도 돼. 모르는 카드는 자주, 아는 카드는 며칠 뒤에 다시 나와.
  • 단원 끝날 때: 문제 풀기 연습 모드로 풀고 해설 보기
  • 시험 1주 전: 모의고사 모드 → 오답노트의 틀린 문제를 다 맞힐 때까지
  • ⚙️ 설정에 시험 날짜를 넣으면 위에 D-day가 떠.

4. 꼭 알아 둘 것

  • 공부 기록은 이 컴퓨터의 이 브라우저에만 저장돼. 일주일에 한 번 홈 아래쪽 💾 백업 파일 저장을 눌러 줘. 컴퓨터를 바꾸면 📂 백업 불러오기로 옮길 수 있어.
  • 브라우저 '인터넷 사용 기록 삭제'에서 쿠키 및 사이트 데이터를 지우면 기록이 사라질 수 있어. 그때도 백업에서 불러오면 돼.
  • ChatGPT가 만든 문제도 가끔 틀려. 이상하면 교과서로 확인하고 관리 화면에서 고치거나 지워.
  • ChatGPT 답이 너무 길어서 끊기면 개수를 줄여서(카드 20, 문제 15 정도) 다시 부탁해.
